# SkillProof

Live app: https://Ripo2.github.io/skillproof/

SkillProof is a GenLayer-powered professional skill verification app. It connects public work samples, capability tracks, validation results, and public credential views into one verification workflow.

## Features

- Proof-room workflow for evidence and capability mapping.
- Public credential passport at `/passport`.
- Interactive proof visualization.
- GenLayer Studionet integration.
- GitHub Pages deployment through GitHub Actions.
