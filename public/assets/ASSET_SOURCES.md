# Asset Sources

SkillProof does not use generated or stock imagery.

- Proof braid visualization: original runtime graphics implemented with PixiJS.
- Interface icons: Lucide React.
- Typography: Space Grotesk and IBM Plex Mono from Fontsource.
- Palette direction: ColorHunt research translated into an original
  off-white, graphite, signal coral, mineral blue, and chartreuse system.
